## 🟣 Featured Projects

<details open>
<summary><b>🧠 CIFAR-10 Image Recognition using Convolutional Neural Networks</b></summary>
<br/>

A deep learning image classification system trained on the CIFAR-10 dataset — 60,000 32×32 color images spanning 10 object categories — built with a custom CNN architecture and full preprocessing pipeline.

| Aspect | Detail |
|---|---|
| **Stack** | Python, TensorFlow, Keras, OpenCV |
| **Scale** | 60,000 images · 50,000 used for training · 10-class classification |
| **Performance** | 94% test accuracy |
| **Security** | Local, self-contained training pipeline — no external data exposure |
| **Impact** | Demonstrates end-to-end computer vision workflow: preprocessing → architecture design → training → evaluation |
| **Repository** | [github.com/neilsharma999/cifar10-cnn-image-recognition](https://github.com/neilsharma999/cifar10-cnn-image-recognition) |

Designed and implemented a 6-layer CNN architecture from scratch, covering convolutional feature extraction, pooling, and dense classification layers. Focused on clean data preprocessing (normalization, augmentation) and rigorous evaluation across all 10 output classes — airplane, automobile, bird, cat, deer, dog, frog, horse, ship, and truck.

</details>

<details>
<summary><b>🔒 KeyClean — Personal Utility Application</b></summary>
<br/>

A desktop utility that temporarily locks all keyboard and mouse input system-wide — designed to prevent accidental keystrokes and clicks during physical device cleaning.

| Aspect | Detail |
|---|---|
| **Stack** | Python, pynput, CustomTkinter, PyInstaller |
| **Scale** | Single-user desktop application, Windows-targeted |
| **Performance** | Real-time system-wide input interception with negligible latency |
| **Security** | Local-only execution — no network calls, no data collection |
| **Impact** | Solves a genuine everyday hardware-maintenance problem with a lightweight, distributable tool |
| **Repository** | [github.com/neilsharma999/keyclean](https://github.com/neilsharma999) |

Built a responsive four-state input-lock state machine using `pynput` for low-level input interception and `CustomTkinter` for a modern, minimal UI. Packaged the final build into a standalone Windows executable with PyInstaller for zero-dependency distribution.

</details>
